### `account.getOvkSettings` 🔰

Returns:

```json
{
    "response": 
    {
        "avatar_style": 0,
        "style": "ovk", // current user's theme
        "show_rating": 0, // is rating shown
        "nsfw_tolerance": 1, // zero for "Don't blur NSFW posts", one for "Blur NSFW posts", two for "Hide from global feed" (server-side) 
        "post_view": "old",
        "main_page": "my_page"
    }
}
```
